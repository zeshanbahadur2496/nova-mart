# amazon-clone

Full-stack Amazon-style e-commerce app built with Next.js, Prisma, MongoDB, NextAuth, and Stripe.

## Features

- Product catalog, search, cart, and checkout
- User authentication and dashboard
- Admin panel for products and orders
- Multi-market pricing (US default) and delivery
- Stripe payments and Prime subscription support

## Getting Started

1. Install dependencies: `npm install`
2. Copy `.env.example` to `.env.local` and fill in your values
3. Seed the database: `npm run db:seed`
4. Start the dev server: `npm run dev`

## Demo Accounts

- Admin: `admin@example.com` / `Admin@123`
- Customer: `customer@example.com` / `User@123`
